# Predictive Maintenance - Anomaly Detection

## Objective
Detect anomalies in time series sensor data for predictive maintenance.

## Dataset
NASA Turbofan dataset (CMAPSS)

Download NASA CMAPSS FD001 dataset from:
<[link](https://www.kaggle.com/datasets/fareselgohary003/nasa-cmapss-turbofan-engine-rul-dataset?resource=download)>

Place files in:
data/raw

## Approach
- Time series preprocessing
- Autoencoder model for anomaly detection

## Goal
Identify abnormal patterns and visualize anomalies over time
